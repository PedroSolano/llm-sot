# Git Registry v10.1.0

Esta pasta é **autônoma** e corresponde ao conteúdo do repositório `llm-sot`.

Valide antes de publicar:

```bash
python3 validate-registry.py
```

Depois copie o conteúdo desta pasta para o root do checkout `llm-sot` e faça commit/push.

O Control Plane e os clientes WSL **não dependem desta pasta localmente**:
eles consomem o repositório Git configurado.
